# Logistics Delivery Performance & Predictive Analytics 🚚📊

## Project Overview

This project focuses on analyzing logistics delivery performance and developing a foundation for predictive analytics and optimization in supply chain operations.

The project uses the DataCo Smart Supply Chain dataset to explore delivery times, shipping modes, delivery risks, market performance, product categories, and customer segments.

## Objectives

- Analyze logistics delivery performance
- Identify factors associated with late deliveries
- Track important logistics KPIs
- Explore market and product performance
- Build a foundation for predictive delivery analysis
- Develop optimization strategies for logistics operations

## Dataset

The project uses the publicly available **DataCo Smart Supply Chain** dataset.

Dataset contains:
- 180,519 records
- 53 variables
- Shipping and delivery information
- Customer and order information
- Product and sales information
- Market and logistics data

## Key KPIs

- Average Actual Shipping Days
- Average Scheduled Shipping Days
- Late Delivery Risk
- Total Sales
- Total Profit
- Average Order Value
